# Carnet de stage

Page de saisie du carnet de suivi de stage.

Cette page ne contient aucune donnée. Les saisies sont enregistrées dans un dépôt privé, accessible uniquement au tuteur et à la stagiaire. Pour les afficher, il faut se connecter avec un jeton GitHub qui donne accès à ce dépôt.

Adresse de la page : https://ehrmingerm.github.io/carnet_stage-manon/
